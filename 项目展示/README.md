# AI 私人厨师 - 项目展示

本文件夹展示 AI 私人厨师项目的界面截图和功能演示。

## 项目概述

AI 私人厨师是一款智能食谱推荐应用，用户通过上传食材图片或输入食材清单，即可获得个性化的烹饪建议。

## 核心功能

- 🥗 **食材图片上传**：支持上传冰箱食材图片进行智能识别
- 📋 **个性化推荐**：根据用户提供的食材，智能推荐合适的菜谱
- 👨🍳 **详细菜谱**：提供完整的烹饪步骤和食材清单
- 📊 **营养分析**：展示每道菜的营养成分和难度评分

## 界面展示

### 主界面截图

AI 私人厨师的主界面采用简洁现代的设计风格：

- **顶部导航**：品牌 Logo、应用名称、新建会话按钮
- **对话区域**：展示与 AI 助手的对话历史
- **输入区域**：支持文本输入和图片上传
- **菜谱卡片**：展示推荐的菜谱，包含推荐理由、营养得分、难度得分

### 功能演示

当用户上传一张食材图片后，系统会：
1. 识别图片中的食材
2. 根据食材推荐合适的菜谱
3. 展示菜谱详情，包括推荐理由、营养信息和烹饪难度

## 技术栈

- **前端框架**：Next.js
- **后端框架**：FastAPI
- **AI 服务**：OpenAI API、LangChain
- **数据库**：SQLite

## 项目价值

帮助用户充分利用家中现有食材，减少食物浪费，同时提供健康、多样化的饮食建议。
